# Input 2 — Database Fundamentals
A database is an organized collection of related data.
A DBMS is software used to define, create, store, retrieve, and manage databases.
A primary key uniquely identifies each row and cannot be null.
A foreign key refers to a key in another table and helps maintain referential integrity.
Normalization organizes data to reduce redundancy and update anomalies.
SQL commands include DDL (CREATE, ALTER, DROP), DML (INSERT, UPDATE, DELETE), and DQL (SELECT).
