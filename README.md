# Project 16 — Your Own Skill
## Selected skill: `/viva` — Viva Practice Coach

This project turns a successful viva-practice conversation into a reusable skill that works in a fresh chat.

### Required project checks from the assignment
- Starts correctly in a fresh session.
- Works well on 3 different inputs.
- Run the same task without the skill and show what improved.

### Included
- `skill.md`: reusable skill instructions.
- `sample_input_1.md`, `sample_input_2.md`, `sample_input_3.md`: three different test topics.
- `test_plan.md`: step-by-step testing and baseline comparison.
- `results_template.md`: record results and screenshots.
- `submission_checklist.md`: final checklist.

### Run it
1. Open a new ChatGPT or Gemini chat.
2. Paste all text from `skill.md`.
3. Upload one sample input file.
4. Type `/viva` or `Start viva`.
5. Answer questions, use `hint`, `skip`, `review`, and `finish`.
6. Repeat with all three input files.
7. Repeat one test in a separate chat **without** the skill instructions and compare.
8. Capture screenshots and fill in `results_template.md`.

Note: `/viva` is a command convention in the skill prompt, not an actual platform slash-command registration. In a fresh chat, paste `skill.md` first.
